GOOD QUESTIONS

Before you dive in.

Can I explore FinTrack before signing in? ＋

Yes. Choose Explore Features or View Live Demo to browse the dashboard and sample pages. Actions that change personal data ask you to sign in.

What can I do with FinTrack? ＋

Explore transaction tracking, category budgets, savings goals, investment learning options, country-based tax estimators and spending reports.

Are the numbers on this landing page real? ＋

No. The landing page uses illustrative sample data to show how the interface works. The current project is a browser-based demo, not a connected bank account.

Can I switch between dark and light themes? ＋

Yes. Use the theme switch in the navigation. Dark mode uses deep charcoal and neon purple; light mode uses a warm ivory canvas, lavender surfaces and crisp violet accents.
